# 西北太平洋台风模拟器

面向科普与教学的简化西北太平洋热带气旋路径与强度模拟网站（静态页面）。

## 打开方式

任选其一：

1. **本地静态服务（推荐）**

```bash
cd /workspace/typhoon-simulator
python3 -m http.server 8765
```

浏览器打开：http://127.0.0.1:8765/

2. **直接打开文件**

用浏览器打开 `index.html`（需能访问 Leaflet CDN：unpkg.com）。

## 使用简述

1. 在左侧设置经纬度、最大风速（或「或风力等级」），或直接在地图上点击放置台风中心。
2. 选择风力等级会立刻更新显示的强度与七/十/十二级风圈，但**不会**开跑；按「开始」才运动。
3. 按需调节海温、副高、引导气流与图层开关。
4. 风速降到 **7 级以下**（约 &lt;13.9 m/s）后自动结束。

## 文件

- `index.html` — 页面
- `css/style.css` — 普通白灰风格样式
- `js/geo.js` — 地理域、陆地/山地、SST、副高几何
- `js/physics.js` — 运动（引导流+β漂移+副高墙跟随）与强度
- `js/app.js` — Leaflet 地图与界面逻辑
